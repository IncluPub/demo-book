Ein E-Book ist barrierefrei, wenn alle Menschen es lesen können, auch mit Hilfsmitteln wie einem [Screenreader](../../glossary/screenreader.md) oder einer [Braillezeile](../../glossary/braille-display.md). Die Grundlage dafür ist eine saubere Struktur :cite[S. 12]{ref=bibliography.yaml#mueller-2024}.

## Überschriften

Überschriften gliedern den Text. Wer einen Screenreader nutzt, springt von Überschrift zu Überschrift, so wie Sehende ein Inhaltsverzeichnis überfliegen.:footnote[Viele Screenreader springen mit der Taste H zur nächsten Überschrift :cite{ref=bibliography.yaml#schaefer-2025}.]{#qfkbudo5}

:::table[Überschriftenebenen in einem Kapitel]{#m0pl25gq}

| Ebene | Verwendung |
| --- | --- |
| 1 | Titel des Kapitels |
| 2 | Abschnitte |
| 3 | Unterabschnitte |
| 4 | weitere Unterteilung |

:::

:::key-point{#b068eilf}

Überschriftenebenen werden nicht übersprungen: Auf eine Überschrift der Ebene 2 folgt keine der Ebene 4.

:::

## Sprache

Die Sprache eines E-Books ist angegeben, damit die Sprachausgabe die Wörter richtig ausspricht. Für Begriffe wie „WCAG“ hilft ein Aussprachewörterbuch.

:::quote[:cite{ref=bibliography.yaml#wcag-22}]{#pmlusiuj}

Web Content Accessibility Guidelines (WCAG) 2.2 covers a wide range of recommendations for making web content more accessible.

:::

:::question[Übung: Überschriften]{#f5bvnaub interaction=single-choice}

Auf eine Überschrift der Ebene 2 soll ein Unterabschnitt folgen. Welche Ebene hat seine Überschrift?:footnote[Die Ebenen entsprechen den Elementen `h2` bis `h4` im XHTML des E-Books.]{#n3odfto7}

- [ ] Ebene 2 {#iga8y2oz}
- [x] Ebene 3 {#55o9xahz}
- [ ] Ebene 4 {#x54wk0xr}

---

Ein Unterabschnitt steht eine Ebene tiefer, also auf Ebene 3. Ebene 4 würde eine Ebene überspringen.

:::
